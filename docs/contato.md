## O que ajudar a descrever

- Qual assistente (Cursor, Claude, ChatGPT) e se já tem o MCP apontando para `http://127.0.0.1:8787/mcp`.
- O que você quer perguntar — vendas, estoque, carteira, lucratividade, cadastro.
- Se a base local já sincronizou (`wt_vendas_base_local` / `wt_estoque_base_local`).
